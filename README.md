# MakoPulse Desk releases

Signed Windows installers for MakoPulse Desk, the Windows app for the MakoPulse HelpDesk (desk.makopulse.com), published by Mako Logics LLC.

This repository holds release files only. Installed copies check it for updates by themselves, and every installer is signed by Mako Logics LLC. The app refuses to install an update that is not.
